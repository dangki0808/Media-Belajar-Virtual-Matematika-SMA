Nota tiga warung

Tiga warung menjual nasi, mi, dan es teh. Data penjualan harian tersusun rapi dalam tabel baris-kolom: itulah matriks. Kalikan matriks penjualan dengan matriks harga, dan pendapatan setiap warung keluar sekaligus. Matriks juga dipakai di grafik komputer untuk memutar dan memperbesar gambar, di Google untuk mengurutkan halaman, dan di AI untuk mengenali wajah.

1. Ordo dan operasi dasar

Matriks berordo m×n punya m baris dan n kolom. Dua matriks dijumlahkan jika ordonya sama: jumlahkan elemen yang seletak. Perkalian skalar: kalikan semua elemen.

TransposAᵀ menukar baris menjadi kolom. Matriks 2×3 menjadi 3×2.

2. Perkalian dua matriks

A (m×n) × B (n×p) = C (m×p). Elemen cij = baris ke-i A “dikali” kolom ke-j B (kalikan berpasangan lalu jumlahkan). Syarat: banyak kolom A = banyak baris B.

PenerapanWarung A menjual 20 nasi dan 30 es teh; harga nasi 12 ribu, es teh 4 ribu. Pendapatan = [20 30] × [12 ; 4] = 240 + 120 = 360 ribu.
Umumnya AB ≠ BA: perkalian matriks tidak komutatif.

3. Determinan dan invers

Matriks 2×2A = [a b ; c d], det A = ad − bc.
A⁻¹ = (1/det A)·[d −b ; −c a], ada jika det A ≠ 0.
Matriks 3×3 (Sarrus)Salin dua kolom pertama ke kanan; jumlah hasil kali diagonal turun dikurangi jumlah hasil kali diagonal naik.

Sifat: det(AB) = det A · det B, det(Aᵀ) = det A, det(A⁻¹) = 1/det A.

4. SPL dengan matriks

Sistem ax + by = p, cx + dy = q ditulis A·X = B, sehingga X = A⁻¹B. Atau dengan aturan Cramer: x = Dₓ/D, y = D_y/D.

Contoh2x + y = 7, x + 3y = 11: D = 5, Dₓ = 21 − 11 = 10, D_y = 22 − 7 = 15, jadi x = 2, y = 3.

Lab: Matriks sebagai Transformasi

Matriks [a b ; c d] memindahkan setiap titik (x, y) ke (ax + by, cx + dy). Persegi satuan (abu-abu) berubah menjadi jajargenjang (berwarna). Luas jajargenjang = |det|.
