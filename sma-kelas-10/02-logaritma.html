Logaritma: Menanyakan “Pangkat Berapa?”

Setelah modul ini kamu bisa
  • Mengubah bentuk pangkat menjadi logaritma dan sebaliknya.
  • Memakai sifat-sifat logaritma untuk menghitung dan menyederhanakan.
  • Membaca skala logaritma: gempa (Richter), keasaman (pH), dan suara (desibel).

Mulai dari cerita

Berapa lama tabungan menjadi dua kali?

Dengan eksponen kita bertanya: “2 dipangkatkan 5 hasilnya berapa?” (jawab: 32). Logaritma bertanya kebalikannya: “2 dipangkatkan berapa supaya hasilnya 32?” Jawabannya 5, ditulis 2log 32 = 5. Pertanyaan seperti “berapa tahun sampai uangku berlipat?” atau “seberapa kuat gempa ini dibanding yang kemarin?” dijawab dengan logaritma.

1. Definisi

ac = b  ⟺  alog b = c   dengan a > 0, a ≠ 1, b > 0

a disebut basis, b numerus, c hasil logaritma. Jika basis tidak ditulis, basisnya 10: log 1000 = 3.

Contoh3log 81 = 4 sebab 3⁴ = 81
Contoh2log ⅛ = −3 sebab 2⁻³ = ⅛
Khususalog 1 = 0 dan alog a = 1

2. Sifat-sifat logaritma

SifatRumusContoh

Logaritma mengubah perkalian menjadi penjumlahan. Itulah sebabnya dulu para pelaut dan insinyur memakai tabel logaritma untuk menghitung cepat sebelum ada kalkulator.

3. Persamaan logaritma

Jika alog f(x) = c, maka f(x) = ac. Jangan lupa syarat numerus positif.

Contoh2log (x + 3) = 4 → x + 3 = 2⁴ = 16 → x = 13. Cek: x + 3 = 16 > 0 ✓
Penerapan: waktu gandaUang berbunga majemuk 8% per tahun menjadi dua kali saat 1,08ᵗ = 2, jadi t = log 2 / log 1,08 ≈ 9 tahun. (Aturan praktis “72”: 72 : 8 = 9.)
