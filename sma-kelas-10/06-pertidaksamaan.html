Modul 6 · Aljabar MENENGAH

Pertidaksamaan: Bukan Satu Jawaban, tetapi Daerah

Setelah modul ini kamu bisa
  • Menyelesaikan pertidaksamaan linear, kuadrat, dan rasional dengan garis bilangan.
  • Menyelesaikan pertidaksamaan nilai mutlak sebagai soal jarak.
  • Menulis himpunan penyelesaian dalam bentuk interval.

Mulai dari cerita

Batas aman

Lift hanya aman jika beban total tidak lebih dari 800 kg. Suhu vaksin harus antara 2°C dan 8°C. Kecepatan di jalan tol paling sedikit 60 km/jam. Kehidupan penuh dengan batas, dan batas ditulis dengan tanda <, ≤, >, ≥. Jawabannya bukan satu angka, tetapi sekumpulan nilai (interval).

1. Pertidaksamaan linear

Diselesaikan seperti persamaan, dengan satu aturan penting: jika kedua ruas dikali atau dibagi bilangan negatif, tanda dibalik.

Contoh−3x + 5 ≤ 17 → −3x ≤ 12 → x ≥ −4 (tanda dibalik karena dibagi −3). Interval: [−4, ∞).

2. Pertidaksamaan kuadrat dan rasional

  1. Jadikan ruas kanan nol. Contoh: x² − x − 6 < 0.
  2. Cari pembuat nol (akar pembilang dan penyebut): (x + 2)(x − 3) = 0 → x = −2, x = 3.
  3. Gambar garis bilangan, uji satu titik di tiap daerah untuk menentukan tanda + atau −.
  4. Pilih daerah sesuai tanda soal: < 0 pilih daerah −. Jawaban: −2 < x < 3.
Pada pertidaksamaan rasional f(x)/g(x), pembuat nol penyebut tidak pernah ikut (bulatan kosong), karena pembagian dengan nol tidak terdefinisi.

3. Nilai mutlak = jarak

|x − a| artinya jarak x ke a pada garis bilangan.

Jarak kurang dari r|x − a| < r ⟺ a − r < x < a + r
Jarak lebih dari r|x − a| > r ⟺ x < a − r atau x > a + r
PenerapanBerat kemasan gula 1.000 g dengan toleransi 15 g: |b − 1000| ≤ 15 → 985 ≤ b ≤ 1.015.

4. Pertidaksamaan bentuk akar

Untuk √f(x) < c: syaratnya f(x) ≥ 0 (agar akar terdefinisi) dan f(x) < c² (kuadratkan). Jawaban adalah irisan keduanya.

Contoh√(x − 1) < 3 → x ≥ 1 dan x − 1 < 9 → 1 ≤ x < 10.

Lab: Garis Bilangan Tanda

Pilih bentuk, atur pembuat nol p dan q, lalu pilih tanda. Grafik di atas menunjukkan kapan nilai fungsi positif (di atas sumbu) atau negatif.
