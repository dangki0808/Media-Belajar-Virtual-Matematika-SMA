Naik-Turun, Puncak & Lembah: Membaca Grafik dengan Turunan

Setelah modul ini kamu bisa
  • Menentukan kapan grafik naik atau turun dari tanda turunan pertama.
  • Menemukan titik stasioner (puncak, lembah) dengan menyelesaikan f′(x) = 0.
  • Memakai turunan kedua untuk kecekungan, titik belok, dan uji maksimum-minimum.

Mulai dari cerita

Cerita jalan bukit

Bayangkan naik motor di jalan perbukitan menuju Batu Dulang. Saat jalan menanjak, motor terasa berat (kemiringan positif). Saat menurun, motor meluncur (kemiringan negatif). Tepat di puncak bukit dan di dasar lembah, jalan sejenak mendatar: kemiringannya nol. Turunan adalah kemiringan jalan, jadi turunan bisa memberi tahu kita di mana puncak dan lembah berada, tanpa perlu menggambar seluruh grafik.

1. Naik, turun, dan stasioner

Tanda f′(x)Grafik fSeperti jalan …
f′ > 0naikmenanjak ↗
f′ < 0turunmenurun ↘
f′ = 0stasionermendatar (puncak, lembah, atau dataran)

2. Langkah mencari puncak dan lembah

  1. Hitung f′(x).
  2. Selesaikan f′(x) = 0 untuk mendapat titik stasioner.
  3. Periksa tanda f′ di kiri dan kanan titik: + lalu − berarti maksimum (puncak); − lalu + berarti minimum (lembah).
Contoh: f(x) = x³ − 3xf′(x) = 3x² − 3 = 0 → x = −1 atau x = 1.
x = −1: f′ berubah + ke − → maksimum lokal, f(−1) = 2.
x = 1: f′ berubah − ke + → minimum lokal, f(1) = −2.

3. Turunan kedua: senyum atau cemberut?

f″ adalah turunan dari f′. Ia menunjukkan apakah kemiringan sedang bertambah atau berkurang.

f″ > 0 → cekung ke atas 🙂Seperti mangkuk/senyum. Titik stasioner di sini adalah minimum.
f″ < 0 → cekung ke bawah 🙁Seperti bukit/cemberut. Titik stasioner di sini adalah maksimum.

Titik belok: tempat kecekungan berganti (dari senyum ke cemberut atau sebaliknya), yaitu saat f″ berganti tanda.

Di mana dipakai?

  • Pertanian & pasar: kapan harga cabai mencapai puncak dalam setahun.
  • Kesehatan: pada wabah, titik belok kurva jumlah kasus adalah saat kasus baru per hari paling banyak. Setelah itu wabah mulai melambat.
  • Bisnis: titik belok kurva penjualan produk baru menandai saat pertumbuhan penjualan tercepat.

Lab: Perjalanan di Jalan Bukit

Pilih bentuk jalan, lalu jalankan motornya. Hijau = menanjak (f′ > 0), merah = menurun (f′ < 0), titik kuning = stasioner (f′ = 0).

Lab: Senyum & Cemberut (turunan kedua)

Daerah biru: cekung ke atas (f″ > 0, 🙂). Daerah oranye: cekung ke bawah (f″ < 0, 🙁). Belah ketupat ungu: titik belok.
